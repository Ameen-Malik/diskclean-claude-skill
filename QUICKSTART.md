# 🚀 Quick Start Guide

Get DiskClean running in 60 seconds!

---

## Step 1: Install (30 seconds)

Open Claude Code and run these two commands:

```bash
/plugin marketplace add Ameen-Malik/diskclean-claude-skill
/plugin install diskclean
```

> **Note:** Replace `Ameen-Malik` with the actual GitHub username once published

---

## Step 2: Restart Claude Code (15 seconds)

1. Exit Claude Code completely
2. Reopen Claude Code
3. Start a new session

---

## Step 3: Use It! (15 seconds)

Just ask Claude naturally:

```
"Clean up my D drive"
"Analyze space on C:"
"What's taking up space in Downloads?"
```

---

## That's It! 🎉

The skill will:
1. ✅ Scan your drive
2. ✅ Show what's taking space
3. ✅ Let you choose what to delete
4. ✅ Safely remove files
5. ✅ Show you how much space you freed

---

## First-Time Tips

### Quick Wins Mode
For fast cleanup of obvious duplicates:
```
You: "diskclean D:"
Skill: [Shows auto-selected duplicates]
You: "delete quick wins"
You: "yes"
✨ Done!
```

### Review Before Deleting
For thorough cleanup with full control:
```
You: "Clean my C drive"
Skill: [Shows categories: Quick Wins + Large Items]
You: "details 4" (to see what item 4 is)
Skill: [Shows details, explains if it's safe]
You: "select 4" (mark for deletion)
You: "proceed"
You: "yes"
✨ Space freed!
```

### Natural Language
Just talk normally:
```
"Show me what's in VALORANT"
"Delete all duplicates but keep the games"
"Remove node_modules folders"
```

## Common First Uses

### "My drive is almost full!"
```
"Help me free up space on D drive"
→ Analyzes entire drive
→ Shows top space consumers
→ Guides you through cleanup
```

### "Clean my Downloads folder"
```
"What's taking up space in Downloads?"
→ Analyzes just Downloads
→ Shows large files and duplicates
→ Easy to clean up old installers
```

### "Remove development clutter"
```
"Find all node_modules on my drive"
→ Locates all node_modules
→ Shows sizes and locations
→ Can regenerate with npm install
```
